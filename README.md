# MY SYSTEM

PWA mobile-first de progression personnelle.

## Utilisation
Ouvrir l'application depuis une URL HTTPS puis l'ajouter à l'écran d'accueil sur iPhone.

## Coach
L'interface Coach est prête, mais l'intégration d'un vrai modèle doit passer par un serveur sécurisé afin de ne jamais exposer une clé API dans le navigateur.
